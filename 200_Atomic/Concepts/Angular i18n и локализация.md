# Angular i18n и локализация

## Core Idea
i18n — это подготовка архитектуры приложения к поддержке разных языков и культурных форматов, а локализация (L10n) — процесс адаптации приложения под конкретный язык, регион и правила отображения данных.

## Why It Matters
Позволяет выходить на международные рынки, обеспечивая пользователям естественный интерфейс с родным языком, правильными форматами дат, валют и правилами множественных чисел.

## Key Points

- **Compile-time vs Runtime:** Родной `@angular/localize` собирает отдельные быстрые бандлы под каждый язык на этапе сборки; библиотеки вроде Transloco подгружают JSON-переводы динамически в рантайме.
  
- **Не только текст:** Локализация включает форматирование чисел, дат, времени, валют и адаптацию направления текста (LTR / RTL).
  
- **ICU Message Format:** Стандарт для обработки сложных языковых правил (плюрализация, гендерные формы) прямо в шаблонах.
  
- **Взаимодействие с SSR:** Динамическая смена языка на клиенте через `localStorage` при SSR может вызывать Hydration Mismatch, если сервер не знает язык пользователя (нужно передавать язык через URL или Cookies).

## Examples

### Example 1
Производство будильника.  
i18n — это создание дисплея, способного выводить любые символы.  
L10n — зашивка в память названий дней недели на японском и настройка иены вместо доллара.

### Example 2
Международный банк.  
Для пользователя из США сумма отображается как `$1,254.50` (месяц/день/год), а для пользователя из Германии — как `1.254,50 €` (день.месяц.год).

## How to Apply

1. Размечать статические строки в шаблонах атрибутом `i18n` (для встроенного Angular i18n) или использовать ключи переводов с Transloco / ngx-translate.
2. Настроить экстракцию сообщений (`ng extract-i18n`) в файлы `.xlf` или `.json` для передачи переводчикам.
3. Использовать встроенные пайпы Angular (`date`, `currency`, `decimal`) вместо ручного форматирования строк.
4. При SSR передавать выбранную локаль пользователя через параметры URL (`/ru/...`) или заголовки / Cookies, чтобы сервер отдал HTML на правильном языке.
