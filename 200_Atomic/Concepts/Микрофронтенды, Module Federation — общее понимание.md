# Микрофронтенды / Module Federation — общее понимание

## Core Idea

Микрофронтенды делят монолитный фронтенд на автономные независимые приложения, а Module Federation позволяет этим приложениям динамически обмениваться кодом и зависимостями в рантайме через сеть.

## Why It Matters

Позволяет крупным компаниям масштабировать разработку параллельными независимыми командами, ускоряет CI/CD (деплой одной фичи не требует пересборки всего проекта) и снижает риски при релизах.

## Key Points

- **Host vs Remote:** Host работает как контейнер/оболочка, Remote предоставляет изолированные модули/страницы через манифест `remoteEntry.js`.
    
- **Runtime Integration:** Интеграция происходит в браузере во время выполнения, а не на этапе сборки (Build time).
    
- **Shared Singletons:** Module Federation предотвращает дублирование фреймворков и библиотек, расшаривая одинаковые зависимости между Host и Remote.
    
- **Организационный профит:** Каждый микрофронтенд может иметь свой CI/CD пайплайн, свой репозиторий и свою команду.
    

## Examples

### Example 1: Торговый центр

Торговый центр (Host) и магазины арендаторов (Remotes). ТЦ даёт крышу, свет и входную дверь, а каждый магазин автономно обновляет свои витрины.

Служба логистики (Module Federation) поставляет им общие тележки (shared libraries), чтобы не загромождать склад.

### Example 2: Банковское приложение

Команда «Переводы» деплоит свой микрофронтенд независимо от команды «Кредиты».

Если в блоке кредитов упадёт сборка, раздел переводов продолжит работать у пользователей без сбоев.

## How to Apply

1. Выделить зону ответственности приложения на автономные бизнес-домены (например, `shell`, `auth`, `dashboard`).
    
2. Настроить Webpack 5 (или Nx / Rspack / Vite со специальными плагинами) с использованием `ModuleFederationPlugin`.
    
3. Описать в конфигурации Host приложения пути к `remotes`, а в Remote приложениях экспортировать компоненты через `exposes`.
    
4. Настроить массив `shared` для предотвращения повторной загрузки ключевых библиотек (например, фреймворка и UI-кита).
