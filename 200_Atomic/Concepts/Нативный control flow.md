# Нативный control flow (@if/@for/@switch)

## Core Idea
Нативный control flow в Angular — это встроенный в компилятор шаблонов блочный синтаксис (@if, @for, @switch), который заменяет старые структурные директивы (*ngIf, *ngFor, *ngSwitch) для управления отображением элементов без использования внешних модулей и декларативных хаков.

## Why It Matters
Новый синтаксис делает код шаблонов чище, избавляет от необходимости постоянно импортировать CommonModule, обеспечивает строгую проверку типов на этапе компиляции и повышает производительность рендеринга за счет обязательного отслеживания элементов в циклах.

## Key Points
* Отсутствие завязки на модули: Работает из коробки во всех компонентах без явного импорта директив.
* Условные блоки (@if, @else if, @else): Прямая поддержка ветвления условий без использования разметки <ng-template>.
* Оптимизированные циклы (@for): Обязательный параметр track предотвращает лишние перерисовки DOM. Нативная поддержка блока @empty для пустых коллекций.
* Лаконичный выбор (@switch, @case, @default): Сокращает объём шаблонного кода и улучшает читаемость сложных условий.
* Улучшенный DX (Developer Experience): Синтаксис максимально близок к стандартному JavaScript/TypeScript.

## Examples

``` typescript
### Example 1
Динамическое отображение интерфейса на основе статуса авторизации и списка задач:

@if (isLoggedIn) {
  <h2>Ваш список задач:</h2>
  <ul>
    @for (task of tasks; track task.id) {
      <li>{{ task.title }}</li>
    } @empty {
      <li>У вас пока нет активных задач.</li>
    }
  </ul>
} @else {
  <p>Пожалуйста, войдите в систему, чтобы увидеть свои задачи.</p>
}

### Example 2
Обработка ролей пользователей в административной панели:

@switch (user.role) {
  @case ('admin') {
    <app-admin-dashboard />
  }
  @case ('editor') {
    <app-editor-panel />
  }
  @default {
    <app-user-profile />
  }
}
```

## How to Apply
1. Использовать синтаксис в новых компонентах: Писать @if, @for и @switch непосредственно в шаблонах без добавления CommonModule или NgIf/NgFor/NgSwitch в массив imports.
2. Всегда указывать ключ отслеживания в @for: Выбирать уникальный идентификатор объекта (например, track item.id) или индекс (track $index), если у объектов нет ID.
3. Обрабатывать пустые состояния через @empty: Заменять проверки длины массива (items.length === 0) на встроенную секцию @empty внутри @for.
4. Мигрировать существующий проект: Запустить автоматическую CLI-команду миграции Angular "ng g @angular/core:control-flow" для автоматической переработки старых структурных директив во всём проекте.
