# Фундамент веба и языка

### Core Idea
Единая база знаний по ключевым концепциям JavaScript, TypeScript и браузерной веб-платформы, необходимая для перехода на Middle-уровень.

### Why It Matters
Понимание механизмов языка «под капотом» (рантайм, типы, работа браузера) позволяет писать предсказуемый код, оптимизировать производительность и легко проходить углубленные технические собеседования.



### Key Points & Examples

#### 1. JavaScript Runtime & Async
* **Замыкания (Closures):** Функция помнит переменные из своей внешней области видимости.
  * *Example:* Инкапсуляция приватного состояния в `createCounter()`.
* **Прототипы:** Наследование через скрытую ссылку `[[Prototype]]` (`__proto__`).
  * *Example:* Добавление методов в prototype-объект функции-конструктора.
* **Event Loop & Tasks:**
  * *Microtasks* (Promises, `queueMicrotask`) опустошаются полностью сразу после текущего синхронного стека.
  * *Macrotasks* (`setTimeout`, I/O) выполняются по одной за виток Event Loop.
* **async/await & Promise:** Управление асинхронным кодом.
  * *Example:* `await fetch()` вместо цепи `.then()`.
* **Итераторы и Генераторы:**
  * *Итератор:* Объект с `.next()` → `{ value, done }`.
  * *Генератор (`function*` / `yield`):* Функция, возобновляющая исполнение на каждом шаге.

#### 2. TypeScript System
* **Strict mode:** `"strict": true` включает максимальную строгость проверок (например, `strictNullChecks`).
* **Generics:** Параметризованные типы (`Array<T>`, `Response<Data>`).
* **Utility-типы:** `Pick<T, K>` (выбрать), `Omit<T, K>` (исключить), `Partial<T>` (сделать опциональными).
* **Discriminated Unions:** Объединение типов с общим маркерным слотом.
  * *Example:* `{ type: 'success', data } | { type: 'error', error }`.
* **Type Guards & `satisfies`:**
  * *Type Guards:* Предикаты (`val is Type`), `in`, `instanceof` для сужения типов.
  * *`satisfies`:* Проверяет соответствие типу без изменения выведенного итогового типа.

#### 3. Platform & Tools
* **HTTP:**
  * *Методы & Статусы:* GET, POST, PUT, DELETE / 2xx, 3xx, 4xx, 5xx.
  * *Кэш:* `Cache-Control`, `ETag`, `If-None-Match`.
* **Critical Rendering Path (CRP):** HTML/CSS → DOM/CSSOM → Render Tree → Layout → Paint.
* **ESM & Bundlers:** Статический `import`/`export`. Сборщики (Vite, Webpack, esbuild) связывают графы модулей, выполняют Tree Shaking и HMR.



### How to Apply
1. **Разделение сфер:** Используйте JS-рантайм (Event Loop, микротаски) для оптимизации логики, TS-систему (`satisfies`, Discriminated Unions) — для надежности интерфейсов, а CRP/HTTP — для сетевой и визуальной оптимизации.
2. **Дебаг:** При поиске рейсов и лагов проверяйте очередность микротасок в девтулзах и шаги Layout/Paint в вкладке Performance.
