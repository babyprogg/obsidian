# Analytical Thinking

## Core Idea

The ability to see and distinguish logical chains and connections between elements, breaking down complex concepts into understandable components.

## Why It Matters

Analytical thinking = Quality thinking = Quality practices. It's the foundation for understanding complexity, making sound decisions, and building robust mental models.

## Key Points

- **Decomposition** - Breaking elements into smaller parts
- **Finding foundations** - Identifying root causes and basic principles
- **Clarification** - Making vague concepts precise
- **Distinguishing** - Seeing differences between similar things
- **Justification** - Building logical support for claims
- **Refutation** - Identifying flaws in reasoning

## Examples

### Example 1: Debugging Code
Instead of random fixes:
1. Decompose: What system components are involved?
2. Foundation: What's the expected vs actual behavior?
3. Distinguish: Is this a data problem, logic problem, or integration problem?
4. Justify: Why does my hypothesis explain ALL symptoms?

### Example 2: Book Analysis
Not just "I liked it" but:
- What's the core argument?
- How does each chapter support it?
- What evidence is used?
- What assumptions does the author make?

## How to Apply

1. **When facing complexity** - Stop and ask "What are the components here?"
2. **Before accepting conclusions** - Trace the logical chain backwards
3. **During learning** - Don't memorize; understand the structure
4. **In discussions** - Separate facts from interpretations
5. **For decisions** - Map out cause-effect relationships

**Daily practice:**
- Take one concept you use (e.g., "productivity")
- Break it into 3-5 sub-components
- Question which ones actually matter
