# Creative Problem Solving

## Core Idea

Three fundamental modes of creative thinking: Insight (background processing), Convergent (synthesis), and Divergent (exploration).

## Why It Matters

Understanding these three modes helps you choose the right cognitive approach for different problems and deliberately practice each type of creative thinking.

## Key Points

- **Insight** - Idea generation happens in background/subconscious
- **Convergent** - Collecting diverse information and processing into one idea
- **Divergent** - From one problem, generating multiple solution paths

## Examples

### Example 1: Insight Mode
**Scenario:** Stuck on architecture decision for days
**Method:** Stop actively thinking about it, work on something else
**Result:** Solution appears during shower/walk (classic "eureka moment")

**To develop:** Deliberately plant complex problems in your mind, then do unrelated activities

### Example 2: Convergent Thinking
**Scenario:** Building authentication system
**Sources:** OAuth docs, JWT articles, security papers, competitor analysis
**Process:** Synthesize all sources into ONE coherent approach

**To develop:** Pattern recognition exercises, finding commonalities across domains

### Example 3: Divergent Thinking
**Scenario:** User engagement is low
**Divergent:** Brainstorm 20 different solutions:
- Gamification
- Better onboarding
- Social features
- Email campaigns
- Redesign UI
- Add tutorials
- etc.

**To develop:** Default problem-solving practice, force yourself to generate 10+ solutions before choosing

## How to Apply

**Match mode to problem type:**

| Problem Type | Best Mode | Why |
|---|---|---|
| Novel/complex | Insight | Subconscious finds non-obvious connections |
| Research synthesis | Convergent | Many sources → unified understanding |
| Feature brainstorm | Divergent | Need option space before optimizing |

**Weekly practice routine:**
- **Monday AM:** Plant hard problem for insight (don't force solution)
- **Tuesday-Thursday:** Convergent work (research, synthesis, documentation)
- **Friday PM:** Divergent session (brainstorm next week's approach)

**For any problem:**
1. Try divergent first (generate 10 solutions in 15 min)
2. If stuck, switch to convergent (what have others done?)
3. If still stuck, activate insight (work on something else, let it simmer)
