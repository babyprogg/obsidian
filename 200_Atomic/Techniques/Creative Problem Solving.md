# Fundemental methods
1. Insigth
	Генерация идеи в бэкграунде.
	Для прокачки инсайта подойдет сложная проблемы которая застрянет в голове.
2. Convergent
	Сбор множества информации и перерабтотка ее в одну идею
	Для прокачки подойдет опознание паттернов,аналогии и тд. 
3. Divergent
	Проблема и варианты ее решения
	Для прокачки подойдет дефолт проблем солвинг
