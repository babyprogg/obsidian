# Speed Reading

## Core Idea

A technique to increase reading speed while maintaining comprehension by reducing subvocalization, grouping words, and strategic eye movement.

## Why It Matters

Speed reading = More information = Better results = Better you = Better life. In an information-dense world, the ability to efficiently process written material is a competitive advantage.

## Key Points

- **Reduce subvocalization** - Stop "speaking" words in your head
- **Word grouping** - Read phrases/chunks instead of individual words
- **Use a tracker** - Pointer/finger to guide eye movement
- **Read in the middle** - Focus eyes on middle of line to use peripheral vision
- **Comprehension** - Speed without understanding is useless

## Examples

### Example 1: Academic Reading
Before: 200 words/min reading word-by-word
After: 400-600 words/min reading in 3-4 word chunks
Same comprehension but 2-3x throughput

### Example 2: Technical Documentation
Using tracker (cursor/finger) prevents regression (re-reading same lines)
Groups technical terms together for better pattern recognition

## How to Apply

1. **Start with tracker practice** - Use finger/pen to guide reading, prevent regression
2. **Practice chunking** - Consciously try to see 3-4 words at once
3. **Reduce subvocalization** - Count 1-2-3 while reading to break inner voice
4. **Test comprehension** - After each page, summarize in one sentence
5. **Use strategically** - Speed read for broad understanding, slow down for critical passages

**Practice schedule:**
- Week 1: Tracker only (build new habit)
- Week 2: Add chunking (expand visual span)
- Week 3: Reduce subvocalization
- Week 4: Integration
