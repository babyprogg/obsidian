# TRIZ Method

## Core Idea

TRIZ (Теория решения изобретательских задач) is a systematic approach to creative problem-solving using six fundamental techniques to generate innovative solutions.

## Why It Matters

Transforms creativity from "waiting for inspiration" into a systematic process. Provides concrete methods to approach problems from multiple angles and discover non-obvious solutions.

## Key Points

- **Brainstorming** - Generate all possible solutions, even strange ones
- **Synectics/Analogies** - Find similarities between different objects
- **Morphological Analysis** - Solve parts separately, then combine
- **Focal Objects Method** - Apply properties of one object to another
- **Robinson Method** - Find diverse applications for any object
- **System Operator** - Connect objects into systems, find relationships

## Examples

### Example 1: Morphological Analysis - Improving Study Routine
Problem: Ineffective study sessions
Components: Time, Location, Method, Material, Breaks
- Time: Morning/Evening/Night
- Location: Library/Home/Coffee shop
- Method: Reading/Video/Practice
- Breaks: Pomodoro/Circuit/Walk

Test combinations systematically to find optimal system.

### Example 2: Focal Objects - Redesigning Coffee Mug
Take properties from unrelated objects:
- Laptop → Coffee mug with temperature display
- Backpack → Mug with attachment system
- Phone → Self-heating smart mug

### Example 3: Robinson Method
Diploma use cases beyond credential:
- Paperweight
- Table stabilizer
- Frame decoration
- Fire starter (if desperate!)

## How to Apply

**Choose method based on problem type:**

1. **Brainstorming** - When you need quantity of ideas (team problem-solving)
2. **Synectics** - When similar problems were solved in different domains
3. **Morphological Analysis** - For multi-variable optimization problems
4. **Focal Objects** - For product innovation, changing perspectives
5. **Robinson Method** - For resource constraints, creative reuse
6. **System Operator** - For understanding relationships, ecosystem thinking

**General workflow:**
1. Define problem clearly
2. Choose 2-3 TRIZ techniques
3. Generate solutions (10-15 minutes each)
4. Combine best elements
5. Test feasibility
