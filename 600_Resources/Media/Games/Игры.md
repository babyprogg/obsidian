# Игры

Игры, которые я прошёл и о которых что-то записал. Одна заметка = одна игра. Новые появляются в таблице сами.

```dataview
TABLE WITHOUT ID file.link AS "Игра", year AS "Год", rating AS "Оценка", played AS "Прошёл"
FROM "600_Resources/Media/Games"
WHERE type = "game"
SORT played DESC
```
