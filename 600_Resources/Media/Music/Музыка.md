# Музыка

Альбомы и треки, которые я слушал и о которых что-то записал. Одна заметка = один релиз. Новые появляются в таблице сами.

```dataview
TABLE WITHOUT ID file.link AS "Релиз", artist AS "Артист", year AS "Год", rating AS "Оценка", listened AS "Слушал"
FROM "600_Resources/Media/Music"
WHERE type = "music"
SORT listened DESC
```
