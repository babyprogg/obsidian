# Люди

Личности, которые меня зацепили. Сердцем заметки может стать то, почему я вообще начал писать про какую-то личность: чем именно зацепил и что именно я от него хочу перенять, научиться. Шаблон — `person-note`.

```dataview
TABLE WITHOUT ID file.link AS "Кто", field AS "Сфера", created AS "Добавлен"
FROM "600_Resources/People"
WHERE type = "person"
SORT created DESC
```
