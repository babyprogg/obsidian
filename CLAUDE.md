# CLAUDE.md — правила работы с волтом

Это Obsidian-зеттелькастен. Волт — «граф моего мышления». Claude здесь библиотекарь и картограф: собирает, связывает и чинит, но не придумывает за меня.

## Что можно и что нельзя

- **Можно и нужно:** собирать заметки из МОЕГО текста. Вытаскивать мысли из дейликов, склеивать связанные записи в 2–3 сильные заметки (а не много мелких), сохранять мой голос и формулировки, ставить frontmatter, теги и `related:`, добавлять раздел `### Из дневников`. Потом я сам просматриваю и правлю.
- **Нельзя:** генерировать идеи и знания, которых я не писал. Никаких AI-написанных тел заметок.
- **Системные баги — чинить без спроса:** неотрендеренный Templater-код, битые ссылки, лишние символы, неправильные пути в конфигах, мусор из шаблонов, пустые заглушки.
- **Творческое и смысловое — сначала спросить.**
- Obsidian для меня скетчбук: пишу грязно и свободно, косяки исправляет Claude.
- Без эмодзи в заголовках, шаблонах и заметках.

## Дейлики (`500_Areas/Daily/`)

- Мысли в дейликах — только для чтения. Механику (см. выше) — чинить.
- Шаблон: Focus / Captures / Thoughts / Learned / Made / Consumed (`000_System/Templates/daily-note.md`).
- Идеи копятся в дейликах. Недельная заметка заполняется при разборе, а не в течение недели.

## Недельный разбор

- Когда я пишу «разбери неделю» — пройти по дейликам недели и заполнить `000_System/Reviews/Weekly/YYYY-Www.md` (шаблон `weekly-review.md`, неделя начинается с понедельника).
- `## Made` из дейликов → раздел «Сделано за неделю» без чекбоксов, сверху строка «Потреблено: N · Сделано: M». Лупы и наброски считаются. Это зеркало, не план — без оценок.
- Каждый пункт: чекбокс + куда ушёл: `→ [[заметка]]`, `→ Substack`, `→ [[Вишлист]]`, `✗ не надо`.
- То, что можно разложить сразу (мои мысли → заметки, картинки, музыка, вишлист, темы на изучение) — раскладывать и отмечать `[x]`. Решения оставлять мне.
- Незакрытые пункты прошлых недель висят там, где были. На следующую неделю не переносим.

## Теги и метаданные

- Схема из `000_System/Tagging System.md`: `domain/*` + `type/*` (+ `source/*`, `project/<name>`, `connect/*`), плюс плоские тематические теги (`angular`, `rxjs`, `routing`, `architecture`, `music`).
- Без тегов `status/*` и `project/active` — для этого есть свойство `status:`.
- Связи — во frontmatter `related:`.

## Архив

- Не ссылаться из активных заметок на `700_Archive/Legacy`. Битая ссылка лучше ссылки в архив — она отмечает пробел.
- Архив не чистить. Перенос из архива = переместить файл + добавить frontmatter, тело не переписывать, старое имя файла — в `aliases`.
- Ещё не просмотрены мной (AI-написанные): `Gap-Разрыв`, `Интеллектуальные заметки`, три `MOC - *`.

## Анализ связей

- Режим по умолчанию: проанализировать → предложить → ждать. Ссылки, aliases, теги, frontmatter, опечатки и форматирование — можно править сразу.
- Починка ссылки: сохранить мой текст, перенаправить на реальную заметку — `[[Реальная заметка|Мой текст]]`, или добавить `aliases:`.
- Формат отчёта: Strong / Potential / Orphans / Duplicates / Clusters / Gaps / Questions / Metadata cleanup.

## Техническое

- Файлы: UTF-8 без BOM, CRLF.
- Python нет; есть node и git bash (`unix2dos` доступен).
- Волт синхронизируется через obsidian-git. Перед работой — `git pull --ff-only`, если в рабочей копии нет изменений.
