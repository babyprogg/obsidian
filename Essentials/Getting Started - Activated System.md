## Key Principle: Use, Don't Admire

**The trap:** "Wow, this system is beautiful! Let me just organize it more..."

**The truth:** The system works by USING it, not perfecting it.

**Test:**
- Did you apply a technique this week? ✓ System working
- Did you just read about techniques? ✗ Still consuming, not creating

**Your own insight (from Essay):**
"Я не могу просто взяться и делать так, как я хочу"

**The system's answer:**
- MOC Learning Systems: Here's HOW to do things
- MOC Psychology of Creation: Here's WHY you're blocked
- MOC Polymath Architecture: Here's WHAT structure enables doing

**Now do.** The scaffolding is built. Build the house.

4. Log: You crossed one micro-gap

### When Inner Critic Attacks
1. Open [[MOC - Psychology of Creation]]
2. Read "Breaking Points" section
3. Practice cognitive defusion: "I'm having the thought that..."
4. Create anyway

### When Overwhelmed by Interests
1. Open [[MOC - Polymath Architecture]]
2. Read "Focus Seasons System"
3. Choose ONE secondary skill for this quarter
4. Release others (they'll rotate back)

### When Techniques Aren't Working
1. Open [[MOC - Learning Systems]]
2. Check "Personal Learning Experiments" table
3. Try different technique
4. Update table with what actually works for YOU
